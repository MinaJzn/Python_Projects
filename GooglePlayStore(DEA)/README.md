# 📱 Google Play Store Data Analysis

A beginner-friendly **Exploratory Data Analysis (EDA)** project using the Google Play Store dataset and Python.

This project explores app characteristics, ratings, genres, and installation patterns through data analysis and visualization.

## ✨ Features

* Analyzes free and paid apps
* Explores app distribution across genres
* Identifies the most common install thresholds
* Examines the relationship between installs and reviews
* Visualizes app rating distributions
* Explores the relationship between installs and ratings
* Compares reported install thresholds across genres

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
