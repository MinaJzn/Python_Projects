# 🧮 BMI Calculator

A simple and beginner-friendly **BMI (Body Mass Index) Calculator** built with Python .

This project takes your **weight** and **height** as input, calculates your BMI, and tells you whether you are underweight, normal weight, or overweight.

##  Features

*  Takes weight in kilograms (KG)
*  Takes height in meters (M)
*  Calculates BMI using the standard formula
*  Provides a simple weight classification
*  Written entirely in Python
*  Beginner-friendly and easy to understand

## 📐 BMI Formula

The BMI is calculated using:

```text
BMI = Weight / Height²
```

For example:

```text
Weight = 70 KG
Height = 1.75 M

BMI = 70 / (1.75²)
BMI ≈ 22.86
```

## 📊 BMI Categories

| BMI Range | Category      |
| --------- | ------------- |
| Below 18  | Low weight    |
| 18 – 25   | Normal weight |
| Above 25  | Overweight    |
